# Admin Guide

## Accessing the Dashboard
Use the `/admin` slash command in any channel where the bot has access. This will open an ephemeral dashboard visible only to you. You must have Administrator permissions in the server to use this command.

## Available Modules

### 1. Verification Management
Manage how users verify. You can require access codes, captcha, or simple button clicks.

### 2. Access Codes
Generate and revoke access codes. Useful for gated communities or specific roles.

### 3. Server Structure
Setup channels and categories automatically based on best practices.

### 4. Moderation Tools
View warnings, kicks, bans, and configure automod filters.

### 5. Mint Board Management
Schedule and manage upcoming mint events.

### 6. Game Configuration
Enable or disable specific games and configure XP rewards.

### 7. XP & Levels
Adjust level thresholds and manually award/remove XP from users.

### 8. Analytics
View community growth, engagement, and moderation statistics.
