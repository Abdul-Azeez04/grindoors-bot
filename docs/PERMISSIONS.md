# Required Permissions

The bot requires specific permissions to function correctly. We recommend the `Administrator` permission for ease of use, but if you prefer granular control, here are the required permissions:

- **Manage Channels**: To create ticket channels and setup server structure.
- **Manage Roles**: To assign verified roles or level rewards.
- **Kick Members / Ban Members**: For the moderation systems.
- **Send Messages / Send Messages in Threads**: Basic communication.
- **Embed Links**: For formatting nice UI panels.
- **Read Message History**: To process context if needed.
- **Manage Messages**: To clean up bot messages or run automod.
- **Use Application Commands**: Required for slash commands.
